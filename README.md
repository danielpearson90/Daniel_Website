# Daniel Pearson: personal website

A small, plain HTML/CSS academic site (no JavaScript, no external requests), generated by one Python
script from files in `content/`. Requires Python 3.11+ and nothing else. See `SPEC.md` for the design
brief and `templates/MARKUP.md` for the markup patterns.

## Editing content

All content lives in `content/`; each file starts with a comment explaining its format.

- **Publication:** add a BibTeX entry to `content/publications.bib` (`@article`, `@incollection`, `@unpublished`).
  Write the site owner as `{\myname{pearson}}` in `author`. Optional fields: `doi`, `pdf = {files/name.pdf}`
  (file must exist in `static/files/`), `note`.
- **Talk or poster:** add a `@misc` entry to `content/talks.bib` (`title`, `author`, `date`, `howpublished` = event,
  `location`, optional `pdf`).
- **News:** add an `[[item]]` with `date = "YYYY-MM-DD"` and `text` (inline HTML allowed) to `content/news.toml`.
- **Person:** add a `[[member]]` or `[[collaborator]]` to `content/people.toml`.
- **Projects, teaching, bio, links:** `projects.toml`, `teaching.toml`, `site.toml`.
- **Files** (PDFs, CV) go in `static/files/`; the portrait is `static/img/portrait.jpg`.
- Anything in `[square brackets]` is a placeholder to replace.

## Build and preview

```
python3 build.py --check        # parse all content and print a summary
python3 build.py                # regenerate dist/
python3 -m http.server -d dist  # preview at http://localhost:8000
```

`build.py` exits non-zero with a clear message if any content file is malformed. Set `base_url` in
`content/site.toml` once a domain exists to get canonical links and `sitemap.xml`.

## Deploy

```
DEPLOY_HOST=<server> DEPLOY_PATH=/var/www/site [DEPLOY_USER=... DEPLOY_PORT=...] deploy/deploy.sh
```

This builds and rsyncs `dist/` to the server (`--delete`; add `--dry-run` to preview). Server setup for a
Proxmox LXC with Caddy or nginx is described in `deploy/README.md`.
